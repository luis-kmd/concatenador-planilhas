# Concatenador de Planilhas

Aplicação desktop com interface gráfica em Qt criada para unir, tratar e concatenar múltiplas folhas de cálculo numa única estrutura de dados.

## Tecnologias Utilizadas

- **Python 3.x**
- **PyQt / PySide**
- **Pandas** (Tratamento de dados)

## Estrutura do Projeto

- `window.py`: Interface e controlo das janelas do sistema.
- `concatenadorQT.py`: Algoritmo de processamento e junção das folhas de cálculo.
- `concatenadorQT.ui`: Ficheiro de layout da interface gráfica.

## Como Executar

1. Instale as dependências necessárias:
   ```bash
   pip install PyQt5 pandas openpyxl
   
1. Execute o programa:
   ```bash
   python window.py
